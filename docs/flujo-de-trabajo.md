Git Commit: Aparece un nuevo nodo que contiene la captura de los cambios y guarda una referencia apuntando a su nodo padre(el commit anterior). La rama actual(HEAD) avanza automaticamente al nuevo nodo recien creado.

Git Branch: Se creo unicamente un nuevo puntero; no se generan nuevos nodos ni commit en la historia. Queda ubicado exactamente en el mismo commit donde se encuentra HEAD.

Git Checkout: Actualiza HEAD que ahora apunta a la nueva rama.

Git Merge: Quedan integrada la historia de la rama actual y la historia de la rama secundaria que se funciona.
